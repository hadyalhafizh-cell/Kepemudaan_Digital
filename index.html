Tidak Menemukan Menu "Tambahkan ke Layar Utama"?

  • Cari Menu "Instal aplikasi" / "Pasang aplikasi": Pada Chrome versi baru, nama menunya berganti dari "Tambahkan ke layar utama" menjadi "Instal aplikasi" atau "Pasang aplikasi".
  • Jika Membuka dari WhatsApp / IG / TikTok: Dilarang langsung klik menu di sana. Klik titik 3 di kanan atas lalu pilih "Buka di Chrome" terlebih dahulu.
  • Jika Menggunakan Komputer/Laptop: Klik titik 3 di kanan atas Chrome → Simpan dan bagikan → Buat pintasan... / Instal.

Panduan Langkah per Perangkat:

Untuk Android (Google Chrome / Edge):

  1. Buka halaman ini murni di aplikasi Google Chrome.
  2. Klik ikon Titik Tiga (⋮) di pojok kanan atas browser.
  3. Pilih "Instal aplikasi" atau "Tambahkan ke Layar Utama".
  4. Klik "Tambah" atau "Instal". Icon aplikasi akan langsung muncul di layar HP Anda.

Untuk iPhone / iPad (Safari):

  1. Buka halaman ini di browser Safari.
  2. Klik tombol Bagikan (Share) di bagian bawah layar.
  3. Gulir ke bawah dan pilih "Tambahkan ke Layar Utama" (Add to Home Screen).
  4. Klik "Tambah" di pojok kanan atas.
